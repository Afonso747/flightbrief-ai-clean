# FlightBrief AI - Clean Deploy Version

Estrutura limpa para deploy no Streamlit Community Cloud.

## Ficheiro principal

Use este path no Streamlit Community Cloud:

`streamlit_app.py`

## Como correr localmente

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## O que faz

- Upload de um PDF
- Análise rule-based inicial
- Geração de PDF com highlights
- Geração de threat summary em PDF

## Nota

Esta é a versão limpa do protótipo (Entregável 1). As regras ainda são básicas e foram desenhadas para serem melhoradas no Entregável 2.
